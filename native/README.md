# Icewind Dale Weather Helper - native build

A single-file Win32 program in C (`src/main.c`). No framework, no runtime to
install: the exe links only DLLs that ship with Windows (user32, gdi32,
gdiplus, shlwapi, shell32, kernel32, msvcrt) and carries its twelve scene
images and icon as resources.

It does nothing while idle: there are no timers or animation loops, painting
happens only on `WM_PAINT` into a cached back buffer, and the scaled scene and
the 24-hour bar are cached so stepping through hours only copies pixels.

## Build

    native/build.sh        # needs x86_64-w64-mingw32-gcc and windres

Output: `native/build/IcewindDaleWeatherHelper.exe`.
The scene images in `native/assets/` are regenerated by `tools/gen_assets.py`.

## Controls

| Input                  | Action                              |
|------------------------|-------------------------------------|
| New Day button, N, F5  | roll a new 24-hour schedule         |
| Click / drag on bar    | select an hour                      |
| Left / Right           | previous / next hour (wraps)        |
| Home / End             | hour 0 / hour 23                    |
| Wheel, Up/Down, PgUp/PgDn | scroll the description if it does not fit |

## Test hooks

    --seed <u32>     deterministic dice
    --newday         roll a day at start-up
    --hour <0-23>    select this hour after rolling (with --newday)
    --size WxH       initial client size in pixels
    --dump <path>    roll a day, write it to <path> and exit without a window

Dump format (UTF-8): first line is the rolled segments as
`event_id:duration_roll` separated by spaces, then 24 lines
`hour<TAB>event_id<TAB>event name`.

`src/weather_data.h` holds the event texts and the progression table,
transcribed mechanically from the original `main.py`.
